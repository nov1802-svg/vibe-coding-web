함께 지식을 공유하고 성장하는 연구 문화를 전파합니다.

바이브 코딩 웹 개발은 모두의연구소 클래스의 교육 과정입니다. 모두의연구소는 2015년 서울 강남에서 시작한 AI·SW 교육 기업이며, 경쟁이 아닌 상생의 힘으로 사람을 연결하는 커뮤니티형 교육을 운영합니다.

01

상생

순위를 겨루기보다, 지식을 나누며 함께 성장하는 힘을 믿습니다.

02

커뮤니티형 교육

주입식으로 가르치지 않고, 함께 웃고 배우고 성장하는 과정을 소중히 여깁니다.

03

연구하고 나누기

LAB, 스터디, 세미나에서 공부한 과정과 결과를 서로 공유합니다.

04

AI·SW 교육

거꾸로 학습 풀잎스쿨에서 시작해, AI 혁신학교 아이펠과 클래스로 교육을 이어 왔습니다.

결과물로 확인합니다.

바이브 코딩은 만들고 싶은 결과를 설명한 뒤, AI가 제안한 화면을 보며 같이 고쳐 가는 방식입니다. 이 강의에서는 웹페이지가 어떻게 생겼는지부터 프론트엔드, 데이터, 배포가 한 줄로 이어지는 흐름까지 직접 만들어 봅니다.

배우는 것

말 한마디가 화면이 되기까지

01

바이브 코딩

원하는 결과를 설명하고, AI와 역할을 나누며 페이지를 완성하는 흐름을 익힙니다.

02

웹의 큰 그림

화면, 서버, 데이터베이스, API, 배포가 어떻게 맞물리는지 한 번에 봅니다.

03

페이지 만들기

랜딩 페이지와 작은 웹앱을 기획하고, 보고 누르는 화면으로 구현합니다.

04

배포까지

GitHub와 Vercel로 만든 페이지를 올려, 링크로 다른 사람에게 보여 줍니다.

커리큘럼

처음 설명부터 배포까지

  1. 바이브 코딩을 시작하는 법 기존 학습과 다른 점, 만들고 싶은 것을 말로 개발하는 기본 방식
  2. 웹개발의 큰 그림과 첫 실습 웹사이트와 웹앱의 차이, 에디터에서 바로 해 보는 첫 수정
  3. 서비스 기획과 화면 구현 벤치마킹한 웹앱과 기업 랜딩 페이지를 직접 구성
  4. 데이터와 API 연결 문의와 회원 기능처럼, 화면 밖의 데이터와 잇는 경험
  5. GitHub와 Vercel 배포 만든 결과를 인터넷에 올려 나만의 주소로 확인
